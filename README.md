# DSA-DAA (Data Structures & Algorithms / Design & Analysis of Algorithms)

Welcome to the **DSA-DAA** repository! This repository contains implementations and analyses of core Data Structures and Algorithms. The code is written in Python and provided as Jupyter Notebooks, making it easy to run, read, and understand the step-by-step execution of each algorithm.

## 📂 Repository Contents

Below is the list of algorithm implementations available in this repository:

* **[Graph Breadth First Search (BFS)](Graph_Breadth_First_Search_(BFS).ipynb)** - Implementation of the BFS traversal algorithm for graphs.
* **[Heap Sort with Comparison Count](Heap_Sort_with_Comparison_Count.ipynb)** - Implementation of the Heap Sort algorithm, including logic to count the number of comparisons made during execution.
* **[Insertion & Merge Sort with Comparison Count](Insertion_&_Merge_Sort_with_Comparison_Count.ipynb)** - A comparative look at Insertion Sort and Merge Sort, tracking comparison counts to analyze time complexity.
* **[Prim's Algorithm (MST)](Prim's_Algorithm_(MST).ipynb)** - Implementation of Prim's algorithm for finding the Minimum Spanning Tree of a graph.
* **[Strassen's Matrix Multiplication](Strassen's_Matrix_Multiplication.ipynb)** - Implementation of Strassen's divide-and-conquer algorithm for efficient matrix multiplication.

## 🚀 Getting Started

All files in this repository are `.ipynb` (Jupyter Notebook) files. You can view them directly on GitHub or run them interactively by:
1. Cloning this repository to your local machine.
2. Opening the notebooks in [Jupyter](https://jupyter.org/) or [Google Colab](https://colab.research.google.com/).
